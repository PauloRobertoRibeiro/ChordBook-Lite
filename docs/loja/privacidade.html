Política de privacidade

ChordBook Lite · versão 1.0.0 · 7 de setembro de 2026

O ChordBook Lite é um aplicativo de cifras, setlists e modo palco. Não pedimos conta, não temos servidor de usuário e não vendemos dados.

O que fica no aparelho

Músicas, setlists, favoritos, idioma, tema e preferências de palco são gravados só neste aparelho. Não enviamos essa biblioteca para a nuvem.

Internet

O aplicativo pede permissão de internet para abrir, quando você toca, sites de cifras, YouTube ou o WhatsApp. Esses sites têm as próprias políticas. Nós não recebemos o que você pesquisa lá.

Cópias de segurança

Exportar backup gera um arquivo JSON no seu aparelho. Desinstalar o aplicativo ou usar Limpar dados apaga a biblioteca deste aparelho.

Crianças

O aplicativo não é dirigido a menores de 13 anos e não recolhe dados de crianças de forma intencional.
